🚀 Project Overview

This is a web-based restaurant order booking system built as my first full-stack project using vibe coding.

The goal of this project is to allow customers to place orders digitally while sitting at a restaurant table, similar to modern restaurant ordering systems used in smart restaurants.

🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: Python
Database: MySQL
⚙️ Pre-requisites

Make sure you have the following installed before running the project:

Python (latest version recommended)
MySQL Server
Web Browser (Chrome / Edge)
🧠 Development Approach

This project was created using a vibe coding workflow:

Designed the complete idea and structure first
Used ChatGPT to generate:
PRD (Product Requirement Document)
Agent workflow (screen-to-screen flow)
Used ChatGPT and Qwen for coding assistance
🔄 Application Workflow
User opens the frontend interface
User browses menu items
User places an order
Backend processes the request
Data is stored in MySQL database
▶️ How to Run
1️⃣ Start Backend
cd backend/routes
python app.py
2️⃣ Open Frontend

Open the following file in your browser:

frontend/user/index.html
